# Auxilia Web 戦闘仕様の実装状況

参照元: `仕様書/アウクシリア 仕様書(してほしい挙動).md`、`仕様書/ランダムマッチ.md`

## 実装済み

- 11キャラクターと既存Unityデータに基づくHP・移動コスト・攻撃3種
- 3体のブラインドピックと重複選択防止
- 初期HP最大、初期コスト50、ターン開始時のコスト50回復
- 90秒のサーバー管理ターン
- サーバー側の手番・所有権・移動範囲・攻撃範囲・コスト・HP判定
- 敵3体の戦闘不能による勝敗判定
- 両拠点（最大耐久200）と、敵拠点の耐久を0にした時点での勝敗判定
- 敵拠点マスへの移動禁止と、攻撃範囲内の拠点へのサーバー側ダメージ計算
- 行動・攻撃・ダメージ・回復・ターンの戦闘ログ
- プレイヤーの投降による即時敗北・相手勝利の確定
- マッチ成立後の了承操作

## 次段階

- キャラクター・拠点が同時に戦闘不能になった場合の詳細なタイブレーク
- 毒・麻痺・俊足・俊敏化・鈍足・鈍化・威力上昇・出血
- 地雷・まきびし・毒ガス・不変マス、侵入不能マス、城マス
- キャラクターごとの非矩形攻撃範囲（現状は最大距離で判定）
- 特殊攻撃による状態・特殊マスの生成
- 両プレイヤーの了承とロード完了をサーバーで同期する処理
